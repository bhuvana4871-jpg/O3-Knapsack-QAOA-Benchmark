Optimization model

From choices to energy

The source presentation converts the constrained problem to a penalized QUBO and then maps binary variables to Pauli-Z terms.

Objective: maximize Σ vᵢxᵢ
Capacity: Σ wᵢxᵢ ≤ capacity
Binary choices: xᵢ ∈ {0,1}; source penalty P = 3
Mapping: x = (1 − Z) / 2

Original example: five decision bits plus four slack bits (1, 2, 4, 8), nine total. Slack bits for custom data are estimated from capacity.
